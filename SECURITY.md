# Security

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's **Report a vulnerability** button on this repository's Security tab to send a private report.

Include what you found, how to reproduce it, and the impact you expect. You'll get an acknowledgement as soon as possible.

## Scope

- This repository's code (frontend and Base44 backend functions)
- theblockchainlibrary.com

## Secrets

No credentials belong in this repository. API keys and tokens are stored as Base44 app secrets and read by backend functions at runtime. If you spot something that looks like a credential in the code or history, report it privately.
